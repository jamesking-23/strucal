# Embedded fonts

- **Geist** (Regular, Medium, SemiBold) — Vercel, SIL Open Font License 1.1. See `Geist-OFL.txt`.
- **JetBrains Mono** (Regular, Medium, SemiBold) — JetBrains, SIL Open Font License 1.1
  (https://github.com/JetBrains/JetBrainsMono/blob/master/OFL.txt). Taken from the `jetbrains-mono` npm
  package, whose packaging licence is in `jetbrains-mono-npm-package-LICENSE.txt`.

The TTF files were converted from the packages' WOFF2 files without modification of the glyph data.
